K = 2. Exact counts compare integer coordinates. Float counts compare 256×256 display bins, not floating-point bits. Both follow identities, even where equal colours hide a mismatch.

A permutation does not forget.

Each kick shifts whole columns. Each drift shifts whole rows. Neither merges cells. Undo drift, then undo kick.

This changes the numerical model to preserve information. It does not establish that the lattice faithfully simulates every real system.

Mathematical claim: cyclic shifts are bijections; their composition has an inverse.

Numerical illustration: these counts come from this JavaScript run.

Formally verified kernel: the repository’s HOL Light source binds 23 AArch64 instruction words (92 bytes) and proves the forward/backward maps under memory and ABI preconditions.

Outside that proof: this port, the toy, float comparison, calling loop, browser and rendered pixels. No new proof replay is claimed here.
