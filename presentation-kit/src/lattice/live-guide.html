LATTICE ECHO · SPEAKER NOTES · ABOUT 3 MINUTES

Chaos can scramble. Must it forget?

  1. Predict. “Both pictures start alike. We will run 100 steps forward, then 100 backward. Which comes home exactly?” Pause for an answer before choosing Intervene.
  2. Intervene. Press Next. “The lattice rounds its kick to a fixed table. Each step shifts whole columns, then whole rows. Every identity still occupies a distinct cell.” Wait for the step count to settle before Reveal.
  3. Reveal. Press Next. “Reverse the order: undo drift, then undo kick.” Wait until the status says zero steps from home. Read the measured counts: the exact count compares integer coordinates; the floating-point count compares display bins, not bits. Chaotic trajectories amplify floating-point errors.
  4. Establish. Press Next. “Rounding a fixed rule need not discard state information. A permutation has an inverse.” Select a toy identity and press Next half-step four times: kick, drift, undo drift, undo kick. All identities return. The toy wraps modulo 8; the large lattice wraps modulo 256.

Keep the boundaries explicit

The mathematical argument is that cyclic shifts are bijections. The displayed result is a numerical experiment in JavaScript. The repository’s HOL Light source proves the two maps for the exact AArch64 kernel bytes under stated memory and ABI preconditions, plus algebraic round trips. It does not verify this port, its calling loop, the toy, the float comparison, browser execution or rendered pixels. No new proof replay is claimed. Preserving information changes the numerical model; it does not establish physical fidelity.
